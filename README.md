# ИИ-администратор для учебных центров

Сервис из двух частей:

- **Чат для родителей.** Отвечает на вопросы о курсах и ценах, а сложные передаёт администратору. Записывает на пробный урок в свободное время. Встраивается на сайт центра одной строкой или работает по ссылке — например, из Instagram, рекламы или QR-кода.
- **Кабинет центра.** Здесь все заявки, их статусы и комментарии, воронка «заявка → пробный → покупка», ближайшие пробные уроки, вопросы без ответа, настройки курсов, цен, расписания и частых вопросов, выгрузка в Excel.

Работает на Netlify: статические страницы, Functions и Blobs. ИИ-ответы идут через Netlify AI Gateway (Claude), отдельный ключ API не нужен. Пока AI Gateway не активен, бот отвечает по частым вопросам из настроек.

## Страницы

| Адрес | Что это |
| --- | --- |
| `/` | Сайт сервиса для владельцев центров |
| `/demo/` | Демо-сайт вымышленной школы BrightWay English с виджетом |
| `/chat/?c=код-центра` | Чат центра по прямой ссылке |
| `/widget.js` | Скрипт виджета для сайта центра |
| `/cabinet/` | Кабинет центра (демо: `brightway` / `demo2026`) |
| `/admin/` | Создание центров и сброс паролей (по ключу `SUPERADMIN_KEY`) |

## Переменные окружения в Netlify

| Переменная | Зачем |
| --- | --- |
| `SUPERADMIN_KEY` | Ключ к `/admin/`, не короче 12 символов. Без него управление центрами выключено |
| `DEMO_PASSWORD` | Пароль демо-кабинета, по умолчанию `demo2026`. Действует только при первом создании демо-центра |
| `SESSION_SECRET` | Необязательно. Без неё секрет для входа создаётся сам и хранится в Blobs |
| `CHAT_MODEL` | Необязательно. Модель для ответов, по умолчанию `claude-haiku-5-5` |

## Как подключить новый центр

1. Откройте `/admin/`, введите `SUPERADMIN_KEY` и создайте центр: код (латиницей), название и пароль.
2. Войдите в `/cabinet/` под этим кодом и паролем. Заполните курсы, цены, адрес, время пробных уроков и частые вопросы.
3. На вкладке «Установка» скопируйте код виджета для сайта или ссылку на чат.

## Устройство

```
netlify/functions/public.mts   чат, запись, вход: /api/public/:center, /api/chat, /api/book, /api/login
netlify/functions/cabinet.mts  кабинет: /api/cabinet/*
netlify/functions/admin.mts    управление центрами: /api/admin/*
netlify/lib/core.mts           хранилище, пароли, токены, слоты
netlify/lib/ai.mts             ответы через Claude и запасной поиск по FAQ
netlify/lib/seed.mts           данные демо-центра
public/                        страницы без сборки
```

Где лежат данные (Netlify Blobs):

- `centers` — центры и их настройки;
- `leads` — заявки;
- `slot-index` — занятые места на пробных уроках;
- `questions` — вопросы из чата.

Перед записью клиент даёт согласие на обработку имени и телефона, время согласия сохраняется в заявке.
