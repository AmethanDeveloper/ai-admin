WhatsApp центра

  1. В Meta for Developers создайте приложение с вариантом «Связаться с клиентами через WhatsApp» и добавьте номер центра.
  2. Скопируйте сюда Phone number ID и постоянный токен (системный пользователь в Business Settings с правами whatsapp_business_messaging).
  3. В разделе Webhooks приложения укажите адрес и verify token из блока «Подключения сервиса» и подпишитесь на поле messages.
  4. App secret приложения (Settings → Basic) — сюда или в переменную WA_APP_SECRET.

Шаблон нужен для напоминаний, если клиент не писал больше суток. Тело шаблона в Meta: «Напоминаем: пробный урок {{1}} в «{{2}}». Адрес: {{3}}.», категория Utility.
